# Flutter Course Explorer

Flutter Course Explorer is a simple educational mobile application developed using Flutter. The application demonstrates screen navigation, custom widgets, a navigation drawer, and a bottom navigation bar while presenting course information in a clean and user-friendly interface.

## Features

- Home screen displaying course information
- Course detail screen
- User profile screen
- Settings screen
- Navigation Drawer
- Bottom Navigation Bar
- Responsive Material Design UI
- Image assets support

## Technologies Used

- Flutter
- Dart
- Material Design

## Application Flow

1. The application opens on the Home Screen.
2. Users can view course information.
3. Selecting a course opens the Course Detail Screen.
4. The Navigation Drawer provides access to additional options.
5. The Bottom Navigation Bar allows navigation between Home and Profile screens.
6. The Settings screen provides application settings.

## Requirements

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android Emulator or Physical Device

## Installation

1. Clone the repository.

```bash
git clone https://github.com/yourusername/flutter-course-explorer.git
```

2. Open the project.

```bash
cd flutter-course-explorer
```

3. Install dependencies.

```bash
flutter pub get
```

4. Run the application.

```bash
flutter run
```
